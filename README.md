# blog-comments

Comments for [blog.craftworks.ltd](https://blog.craftworks.ltd), powered by
[Giscus](https://giscus.app) on top of GitHub Discussions.

with its author.

royalty-free license to use the comment on the blog and in its related
distribution, including displaying, quoting, summarizing, and editing it.
